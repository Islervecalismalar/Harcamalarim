# Harcamalarım

Kişisel aylık harcama, borç ve kredi kartı takip uygulaması (Windows ve Android).

**İndirme:** [Releases](../../releases/latest) sayfasından `Harcamalarim.apk` (Android) veya `Harcamalarim.zip` (Windows) dosyasını indirin. Uygulama yeni sürümleri kendisi denetler.

- Verileriniz yalnızca cihazınızda tutulur; hesap veya üyelik gerekmez.
- İsteğe bağlı, şifreli bilgisayar–telefon eşitleme.

Bu depo yalnızca yayın dosyaları içindir. Kaynak kod herkese açık değildir.
